# ESP32 → STM32 无线 OTA 桥（手机浏览器升级）

用一块 ESP32 当"WiFi 转串口 + 协议翻译器"：手机连 ESP32 的热点，浏览器里点按钮就能**读版本号、擦除、选 .bin 升级**。
STM32 端**一行代码都不用改**——它只是以为对面还是那个 CH340。

```
手机浏览器  ──WiFi──▶  ESP32（AP + 网页 + Xmodem 发送）  ──UART 921600──▶  STM32 USART1（BootLoader）
```

## 一、买什么

| 关键词（淘宝/立创商城搜） | 说明 | 参考价 |
|---|---|---|
| **ESP32 DevKit V1 / ESP32-WROOM-32 开发板**（30 pin，Type-C 或 Micro-USB） | 最省事，Arduino 直接支持 | ¥18~30 |
| 杜邦线（母对母） | 接线用 | ¥5 |
| （可选）逻辑分析仪 | 后面调试用得上 | ¥40~100 |

> 别买 ESP32-C3/S3/C6 的型号，它们 UART 引脚编号不一样，代码要改；先用经典 ESP32-WROOM-32。

## 二、接线（4 根线，加复位是 5 根）

| ESP32 | STM32（Blue Pill / 你的板子） | 说明 |
|---|---|---|
| GPIO17（TX2） | **PA10（USART1_RX）** | 数据：ESP32 → STM32 |
| GPIO16（RX2） | **PA9（USART1_TX）** | 数据：STM32 → ESP32 |
| GND | GND | 必须共地 |
| GPIO4（可选） | **NRST**（复位脚） | 桥接端可以自动复位板子，强烈建议接 |
| 5V/VIN | 不接 | ESP32 自己用 USB 供电，别互相抢电源 |

⚠️ **CH340 和 ESP32 的 TX 不能同时接在 PA10 上**（两个输出会打架）。测试无线升级时，把 CH340 那根 TX/RX 拔掉，或者用跳线切换。

## 三、烧录（Arduino IDE）

1. 安装 Arduino IDE 2.x → 文件 → 首选项 → 附加开发板管理器网址填：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. 开发板管理器搜 `esp32`（Espressif Systems）安装；
3. 开发板选 **ESP32 Dev Module**，端口选 ESP32 的 COM 口；
4. 打开 `esp32_ota_bridge.ino`，直接点上传；
5. 上传完打开串口监视器（115200），能看到：
   ```
   AP: OTA-BRIDGE
   打开 http://192.168.4.1
   ```

## 四、用之前先确认三件事

1. **波特率**：文件顶部 `UART_BAUD = 921600`，必须和你 `usart.c` 里 USART1 的波特率一致；
2. **引脚**：`PIN_UART_RX=16 / PIN_UART_TX=17`，如果你买的是别的板子，按板子丝印改；
3. **复位线**：没接 GPIO4→NRST 的话，把 `USE_RESET` 改成 `false`，然后每次操作前**手动按一下板子的复位键**（页面会等你 5 秒窗口）。

## 五、使用流程

1. 手机连 WiFi：`OTA-BRIDGE`，密码 `Yukino5200`
2. 浏览器打开 `http://192.168.4.1`
3. **读版本号** → 页面显示 `版本号:VER-1.0.0-...`（这一步证明链路通了）
4. 选一个 `.bin` → **上传并升级** → 进度条走完 → "升级成功"，板子自动重启跳新程序

## 六、排错表

| 现象 | 原因 / 怎么查 |
|---|---|
| 页面打不开 | 手机没连上热点；或浏览器拦了 http（换 Chrome/Safari 试） |
| 点"读版本号"显示 `[!] 进不了命令行` | 复位线没接 / 没手动复位 / 波特率不一致 / TX-RX 接反 |
| 一直等到超时，没等到 `C` | MCU 没进 `[2]` 模式（看板子串口输出）；或 `[2]` 擦除太慢（44 页要 1~2 s，属正常） |
| 帧一直重传失败 | 921600 下 ESP32 与 MCU 之间丢字节 → 降到 115200（**两边都要改**：`usart.c` + 本文件） |
| 升级成功但程序跑飞 | 末尾补齐字节不是 0xFF，或 bin 不是从 0x08005000 链接的 A 区程序 |
